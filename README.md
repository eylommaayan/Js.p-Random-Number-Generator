# מחולל מספרים רנדומליים (Random Number Generator)

אפליקציית ווב פשוטה ואינטראקטיבית להגרלת מספרים שלמים בטווח של 1 עד 100 בלחיצת כפתור, שנבנתה באמצעות HTML, CSS ו-JavaScript נקי (Vanilla JS).

## מה נלמד בפרויקט?
* **מניפולציות DOM:** שימוש ב-`querySelector` לבחירת אלמנטים וב-`innerHTML` לעדכון התוכן הדינמי בדף.
* **אירועים (Event Listeners):** קישור פונקציות לאירוע `click` על אלמנט כפתור.
* **פונקציות מתמטיות ב-JS:** הבנת השימוש ב-`Math.random()` לייצור מספרים עשרוניים ו-`Math.floor()` לעיגול כלפי מטה.
* **עיצוב וממשק:** מרכוז אלמנטים ב-Flexbox, שילוב משתני CSS (`:root`) ואייקונים של Font Awesome.

## מבנה הקבצים
* `index.html` – מבנה הדף, הכרטיסייה והכפתור.
* `styles.css` – סגנונות עיצוב, צבעים וריכוז התצוגה.
* `script.js` – הלוגיקה של הגרלת המספר והזרקתו למסך.
